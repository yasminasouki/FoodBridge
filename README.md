# FoodBridge

FoodBridge is a project that connects surplus food with people who need it.

This repository is the starting point for the project.

## Idea

- People and businesses can offer food that would otherwise go to waste.
- People and organizations can request food nearby.
- The bridge between the two is simple: list what is available, and match it with a request.

## Next steps

- Decide who the first users are (households, restaurants, or community groups).
- Sketch the main flow: offer food, request food, and confirm a pickup.
- Build the first small version of that flow.
